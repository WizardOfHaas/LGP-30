## Build and Run (Vite)

```shell
## Change to the project directory
cd ts-lgp-30-html5

## Install tools
npm i
npm ci

## Run tests
npm test

## Build dist
npm run vite:build

## Run local webpage
npm run vite:dev
# type o then enter to open page in browser

## Run the dist version
npm run vite:serve-dist
# open your browser to http://127.0.0.1:8080
# hit ctrl + F5 to flush and refresh your browser if favicon is not visible

## Test using vitest
npm run vite:test
# a work in progress ...

# Create documentation
npm run docs:clean
# clean old docs
npm run docs
# open docs/index.html in your browser
```

## Deploy to cloudflare (Development Phase Only)

```shell
npm run cf:deploy
```

## TS Project Layout

```text
ts-lgp-30-html5/
├── .github/
│   └── workflows/
│       └── main.yml
├── .vscode/ (Cloudflare Dev. Only - IDE settings for wrangler)
├── .wrangler/ (Cloudflare Dev. Only - wrangler working space)
├── dist/ (generated by npm run vite:build)
├── docs/ (generated by npm run docs)
├── node_modules/ (generated by npm i && npm ci)
├── public/
│   └── favicon.ico (copied by vite:build to dist/favicon.ico)
├── src/
│   ├── index.ts
│   ├── index.test.ts
│   ├── *.ts (other ts files)
│   ├── **/*.ts (other folders and ts files)
│   └── public/
│       └── test.html (sean's original web-page)
├── .gitignore
├── index.html
├── package-lock.json
├── package.json
├── tsconfig.json
└── wrangler.jsonc (Cloudflare Dev. Only)
```

Why this layout (short):

* .github/workflows/ci.yml runs build + tests.
* dist/ is the compile output (ignored in git) deployed to apache servers.
* public/ holds the ico file and is bundled to dist when built.
* src/ contains all project and test TS files.
